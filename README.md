# ✔️ TodoList App React (localStorage)

Esta aplicación es un gestor de tareas (Todo List) desarrollado con React, que permite organizar tus pendientes de manera sencilla y visual. Todas las tareas se almacenan en el navegador utilizando **localStorage**, por lo que no necesitas una base de datos externa y tus datos se mantienen aunque cierres la página.


## 📝 ¿Qué es y cómo funciona?

**TodoList App** te permite crear, visualizar, marcar como completadas y eliminar tareas. Puedes organizar tus tareas por día, semana, mes o año, facilitando la gestión de tus actividades a corto y largo plazo.  
La interfaz es intuitiva y responsiva, adaptándose a cualquier dispositivo.

### Características principales:
- Añadir nuevas tareas con facilidad.
- Visualizar tareas por diferentes periodos de tiempo (día, semana, mes, año).
- Marcar tareas como completadas o pendientes.
- Eliminar tareas que ya no necesitas.
- Persistencia de datos usando localStorage.

## 📦 Instalación y uso


1. Accede a la carpeta del proyecto:
    ```
    cd todo-list-app
    ```
2. Instala las dependencias:
    ```
    npm install
    ```
3. Inicia la aplicación en modo desarrollo:
    ```
    npm run dev
    ```

## ⚙ Tecnologías utilizadas

- [React 18](https://reactjs.org/)
- [Vercel](https://vercel.com/) (para el despliegue)
- [Tailwind CSS](https://tailwindcss.com/) (para los estilos)
